# Scholastic frontend

React app for the Scholastic reading tracker (Create React App). Teachers manage classes and assignments; students log reading.

## Run

```bash
npm start
```

Dev server: [http://localhost:3000](http://localhost:3000).

Set `REACT_APP_API_URL` in `.env` (defaults in this repo: `http://127.0.0.1:5000`).

```bash
npm run build
```

Production build goes to `build/`.
